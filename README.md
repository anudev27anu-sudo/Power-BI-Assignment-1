# Power-BI-Assignment-1
Data Import: Imported List of Orders, Order Details, and Sales Target CSV files.

Data Transformation: Kept the first 500 rows, corrected data types, formatted customer names, merged City and State, and created Profit Margin and Profit Status columns.

Data Merging: Combined List of Orders and Order Details using Order ID with a Left Outer join.

Data Cleaning: Checked missing values and duplicate records.

Sorting and Filtering: Sorted orders by date in descending order and filtered orders by Tamil Nadu.

Grouping and Aggregation: Calculated order counts, average profit by category, total amount by sub-category, and monthly sales targets.

Data Modeling: Established relationships using Order ID and Category between the respective tables.

Outcome: Prepared and structured sales data for analysis of orders, profitability, sales targets, and regional performance.
